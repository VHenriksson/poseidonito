# About

Poseidonito is a small Rust workspace showcasing the Poseidon permutation and a
generic sponge construction. It currently provides one preset configuration
(`x5_254_3`) and includes a tiny profiling crate for simple benchmarks.

The logo was generated by DALL·E just for fun.

## Repository Layout

- `src/` – main library implementation
- `profiling/` – benchmark binary
- `docs/` – project documentation written with [mdBook](https://rust-lang.github.io/mdBook/)

## Building and Testing

```
cargo test
```

This compiles the library and runs all tests. The profiling binary can be run
with:

```
cargo run -p profiling
```

## Generating Documentation

The detailed documentation is located under `docs/` and built with mdBook.
Install the tool once via:

```
cargo install mdbook
```

Then generate the HTML documentation with:

```
mdbook build docs
```

The rendered files will appear in `docs/book`. You can open `index.html` there
or run `mdbook serve docs` to preview it locally.
